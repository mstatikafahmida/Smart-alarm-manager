# Smart Alarm Manager

Smart Alarm Manager is a desktop alarm application built with Electron.js. It allows users to create and manage alarms with desktop notifications, snooze support, and a simple user-friendly interface.

## Features
- Live clock and date
- Add, edit, and delete alarms
- Enable or disable alarms
- Desktop notifications
- Snooze and stop alarm
- Dark mode
- Automatically saves alarms

## Built With
- Electron.js
- HTML
- CSS
- JavaScript

## Run
```bash
npm install
npm start
```
